#### 3. **questionController.js** - SSE Endpoint
```javascript
exports.generalChat = async (req, res) => {
  const { message, context, stream = true } = req.body;

  if (stream) {
    // Set SSE headers
    res.setHeader('Content-Type', 'text/event-stream');
    res.setHeader('Cache-Control', 'no-cache');
    res.setHeader('Connection', 'keep-alive');
    res.setHeader('X-Accel-Buffering', 'no');

    // Stream chunks
    await generalChat(message, context, {
      stream: true,
      onChunk: (chunk) => {
        res.write(`data: ${JSON.stringify({ type: 'chunk', content: chunk })}\n\n`);
      }
    });

    // Send completion
    res.write('data: {"type":"done"}\n\n');
    res.end();
  }
}
```

**SSE Message Types:**
- `connected` - Initial connection established
- `chunk` - Content chunk with text
- `done` - Streaming complete
- `error` - Error occurred

### Frontend Changes

#### 1. **GlobalAIChatbot.jsx** - Streaming Handler
```javascript
const handleSend = async () => {
  // Add empty assistant message
  setMessages(prev => [...prev, { role: 'assistant', content: '', streaming: true }]);

  // Fetch with streaming
  const response = await fetch('/api/questions/general-chat', {
    method: 'POST',
    body: JSON.stringify({ message: userMessage, stream: true })
  });

  // Read stream
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let accumulatedContent = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value, { stream: true });
    const lines = chunk.split('\n');

    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const data = JSON.parse(line.slice(6));
        
        if (data.type === 'chunk') {
          accumulatedContent += data.content;
          // Update message with accumulated content
          setMessages(prev => {
            const newMessages = [...prev];
            newMessages[assistantMessageIndex] = {
              role: 'assistant',
              content: accumulatedContent,
              streaming: true
            };
            return newMessages;
          });
        }
      }
    }
  }
}
```

**Key Features:**
- Uses Fetch API with ReadableStream
- Parses SSE format (`data: {...}`)
- Accumulates content progressively
- Updates UI in real-time

## State Management

### Frontend States:
- `isLoading` - Request in progress
- `isStreaming` - Currently receiving stream
- `messages[].streaming` - Individual message streaming state

### State Flow:
1. User sends message → `isLoading = true`, `isStreaming = true`
2. Empty assistant message added with `streaming: true`
3. Chunks received → Message content updated progressively
4. Stream complete → `streaming: false`, `isLoading = false`

- Automatic reconnection on connection loss

## Troubleshooting

### Issue: No streaming, full response appears at once
**Solution:** Check if `stream: true` is being sent in request body

### Issue: Cursor not blinking
**Solution:** Verify `streaming: true` flag is set on message object

### Issue: Connection timeout
**Solution:** Increase timeout in xaiClient.js or check network

### Issue: Chunks not parsing
**Solution:** Verify SSE format: `data: {...}\n\n`
